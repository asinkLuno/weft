# WEFT 用户文档

WEFT 用一个 `.weft` 纯文本文件描述故事：由 **6 个正交顶层声明**（元信息、时间锚点、实体、剧情事件、事件列表与带代数约束的同质关系图）构成。写好后用 `weft` 命令检查语法与逻辑防穿帮、统一排版格式，应用负责把它渲染成交互式故事视图。

- 第一次写：从[语言指南](weft-syntax.md)的“最小文档”与“核心模型”开始。
- 自定义非公历时间轴或实体派生属性：见[自定义历法与可计算属性](rune-plugins.md)。
- 检查语法、导出 JSON、统一格式：见 [weft CLI](weft-cli.md)。
- 在编辑器里边写边看诊断、补全、悬停与跳转：见[语言服务器（LSP）](lsp.md)。
- 让 AI 客户端帮你写：见[在 AI 客户端安装 skill](skills.md)。
- 完整参考示例：仓库中的 `examples/story.weft`。

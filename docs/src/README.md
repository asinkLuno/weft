# Weft 用户文档

Weft 用一个 `.weft` 文本文件描述故事：元信息、实体与归属、实体关系、事件和事件列表。写好后用 `weft` 命令检查并格式化，应用负责把它渲染成故事。

- 第一次写：从[语言指南](weft-syntax.md)的“最小文档”开始。
- 检查语法、统一格式：见 [weft CLI](weft-cli.md)。
- 在编辑器里边写边看诊断、补全、悬停与跳转：见 [语言服务器（LSP）](lsp.md)。
- 让 AI 客户端帮你写：见 [在 AI 客户端安装 skill](skills.md)。
- 完整示例：仓库中的 `examples/story.weft`。

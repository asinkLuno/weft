# WEFT 语言指南

WEFT（`.weft`）是故事文档的领域语言。一个文件描述故事的元信息、实体与归属、实体关系、事件和事件列表，由 `weft-core` 编译成 JSON 交给前端。

语法是类 HCL 的声明式块语言：顶层声明 + `key = value` 属性 + 注释。不需要分号，属性之间用换行分隔，可选逗号/分号。写完后用 [`weft check` / `weft fmt`](weft-cli.md) 检查与格式化。

## 最小文档

```weft
story {
  title = "无题"
}

entity 主角 {
  description = "一个还没有故事的人。"
}

event 开场 {
  start    = [2024, 1, 1]
  entities = [主角]
}

events 主线 = [开场]
```

`story` 和事件的 `start` 是必填项，其余都可省略。下面的章节按“怎么读源码”的顺序展开。

## 词法

- **注释**：`# ...` 与 `// ...` 到行尾；`/* ... */` 跨行。字符串里的符号不算注释。注释会被 `fmt` 保留。
- **名字**：字母或 `_` 开头，后续可以是字母、数字、`_`、`·`、`・`。中文可以直接裸写（`entity 哈利·波特`、`entity 霍格沃茨魔法学校`）。含空格、`·`/`・` 以外的标点、斜杠，或以数字开头，或与 `true` / `false` / `null` 同名时，必须用双引号包起来：`entity "9又3/4站台"`。
- **字符串**：单行 `"..."` 支持 `\\`、`\"`、`\n`、`\r`、`\t`；`"""..."""` 是多行字符串，会自动去掉所有非空行的公共缩进，开头和结尾的换行不计入内容。`description` 适合用多行字符串。
- **数字**：整数与浮点（`42`、`3.14`）；负号写在表达式里（`-1`），时间分量本身不接受负数。
- **字面量**：`true`、`false`、`null`。
- **列表与对象**：`[a, b]`、`{ key = "value" }`。元素间可以用逗号或分号，允许尾逗号。嵌套任意层。
- **字符串字段必须加引号**：`description`、`avatar`、`date_mode` 只接受字符串字面量，裸标识符会报 `invalid-field: expected a string`。名字列表（`belong_to`、`tags`、`entities`、`calculable_props`、`events`）里的裸标识符才按名字处理。
- **名字不是变量**：裸标识符出现在普通属性里就是字符串，只有时间字段里的名字才按时间引用解析。

## 顶层声明

| 声明                           | 作用                                 |
| ------------------------------ | ------------------------------------ |
| `story { ... }`                | 故事元信息，只能有一个               |
| `time <name> = <expr>`         | 命名时间锚点，可在任意时间字段里复用 |
| `entity <name> { ... }`        | 实体：人物、团体、地点、道具都算     |
| `link <group> { ... }`         | 一组实体关系                         |
| `event <name> { ... }`         | 事件                                 |
| `events <name> = [event, ...]` | 事件列表：有序的事件列表             |

### story

```weft
story {
  title            = "哈利·波特与魔法石"
  author           = "J.K. 罗琳"
  description      = """
    十一岁的哈利·波特进入霍格沃茨魔法学校。
  """
  date_mode        = "calendars/custom.rn"   # 省略则用内置公历
  calculable_props = { constellation = "constellation.rn" }
}
```

| 字段               | 必填 | 说明                                  |
| ------------------ | ---- | ------------------------------------- |
| `title`            | 是   | 故事标题                              |
| `author`           | 否   | 作者                                  |
| `description`      | 否   | 简介                                  |
| `date_mode`        | 否   | 历法 Rune 脚本路径，相对 `.weft` 文件 |
| `calculable_props` | 否   | 可计算属性注册表：ID → `.rn` 路径     |

`story` 块重复、`title` 缺失、出现表外字段都是错误。重复属性是警告（后写的值生效）。

### entity

```weft
entity 哈利·波特 {
  description      = "大难不死的男孩。"
  base_time        = [1980, 7, 31]
  belong_to        = [格兰芬多, 波特一家]
  tags             = [巫师, 学生, 主角]
  calculable_props = [constellation]
  avatar           = "images/harry.png"

  # 表外字段原样透传到前端的 extra_props
  gender = "男"
  wand   = "冬青木魔杖，凤凰羽毛杖芯"
}
```

| 字段               | 说明                                                                              |
| ------------------ | --------------------------------------------------------------------------------- |
| `base_time`        | 出生/起始时间，时间表达式                                                         |
| `description`      | 描述，字符串                                                                      |
| `avatar`           | 图片路径，相对 `.weft` 所在目录；必须是已存在的 bmp/gif/ico/jpeg/jpg/png/svg/webp |
| `belong_to`        | 上级实体列表，构成归属 DAG                                                        |
| `tags`             | 实体标签列表（免声明，支持裸标识符或字符串），用于分类与前端多选筛选              |
| `calculable_props` | 启用的可计算属性 ID 列表，结果写进 `extra_props`                                  |

不在上表里的键不会报错，会原样收进 `extra_props`。值可以是标量、列表或对象，但不能是时间引用或 `+` / `-` 表达式。归属引用必须存在且不能成环。`base_time` 不是必填，但可计算属性可能要求它。

### time

```weft
time 开学 = [1991, 9, 1, 19]

event 分院 {
  start = 开学
  end   = 开学 + [0, 0, 0, 2]
}
```

锚点可以出现在任何时间字段里；声明但从未使用会产生 `unused-time-anchor` 警告。锚点名字同样遵循标识符规则。

### link

```weft
link 波特一家 {
  哈利·波特 -- "母子" -- 莉莉·波特
  哈利·波特 -- "父子" -- 詹姆·波特
  莉莉·波特 -- "夫妻" -- 詹姆·波特
}

link 对立与羁绊 {
  伏地魔 -- "追杀" -> 哈利·波特
  奇洛 -- "效忠" -> 伏地魔
  哈利·波特 <- "庇护" -- 阿不思·邓布利多
}
```

每条边支持三种写法（同一组内可混写）：

- **无向**：`A -- "关系" -- B`
- **有向（A → B）**：`A -- "关系" -> B`
- **反向有向（B → A）**：`A <- "关系" -- B`（语义等价于 `B -- "关系" -> A`）

两端必须是已声明实体，关系按字符串处理（可以不写引号，`fmt` 会统一补上）。自己连自己（`self-link`）和重复边（`duplicate-link`，无向边忽略端点顺序、有向边区分方向且 `A <- rel -- B` 与 `B -- rel -> A` 视为同边）是警告，空块是 `empty-block` 警告。同一组可以出现多次，边会合并。

### event

```weft
event 开学宴分院 {
  start       = [1991, 9, 1, 19]
  end         = start + [0, 0, 0, 2]
  entities    = [哈利·波特, 罗恩, 赫敏, 分院帽, 礼堂]
  description = "分院帽把新生分入四大学院。"
}
```

| 字段          | 必填 | 说明                     |
| ------------- | ---- | ------------------------ |
| `start`       | 是   | 开始时间                 |
| `end`         | 否   | 结束时间；早于开始会报错 |
| `entities`    | 否   | 参与实体列表             |
| `description` | 否   | 描述                     |

出现表外字段是错误（不像 `entity` 会收进 `extra_props`）。事件名全局唯一。

### events

```weft
events 哈利的第一学年 = [
  开学宴分院,
  万圣节巨怪入侵,
  地牢最终对决,
]
```

事件必须已声明；列表顺序就是展示顺序；重复引用同一事件不会报错，但顺序照写。空事件列表是 `empty-block` 警告；如果声明了事件列表，却没有被任何事件列表引用的事件，会产生 `unreferenced-event` 警告。

## 时间表达式

时间字段（`base_time`、`start`、`end`、`time` 锚点）支持四种写法：

```weft
time year_only = 1991                    # 单个整数 == [1991]
time full      = [1991, 9, 1, 19, 30, 0] # 年 月 日 时 分 秒
time short     = [1991, 9]               # 可以省略尾部

event 后续 {
  start = 开学宴分院.start + [0, 0, 1]   # 跨事件引用 + 偏移
  end   = 开学宴分院.start - [0, 0, 7]
}
```

- 分量按 `date_mode` 的历法解释，内置公历为 6 分量（年/月/日/时/分/秒）。省略的尾部按历法默认值补齐。
- 引用形式：`锚点名`、`事件名.start`、`事件名.end`、`实体名.base_time`。名字含特殊字符时给基名加引号：`"穿越9又3/4站台".start`。
- 事件内部可以直接写 `start` / `end` 指自己：
  ```weft
  event 宴会 {
    start = [1991, 9, 1, 19]
    end   = start + [0, 0, 0, 2]
  }
  ```
- 偏移右侧必须是整数或整数列表，`+` / `-` 可连续使用；偏移会按历法进位（`[0, 0, 0, 8, 30]` 会自动进到次日）。
- 引用必须存在、不能形成环；嵌套深度上限 64。

时间只是“参考系里的坐标”，不做时区/闰秒等隐式换算，这些由历法脚本的 `normalize` 负责。

## 校验与 lint

`weft check` 分三层：

1. **语法**：词法/语法错误，文件级恢复后尽量把错误全报出来。
2. **语义**：必填字段、未知字段、重复声明、引用存在性、归属成环、时间环、`end < start`、脚本/头像路径、可计算属性注册等。
3. **Lint**：可通过 `--ignore <rule>` 屏蔽的警告：

| 规则                 | 触发条件                                    |
| -------------------- | ------------------------------------------- |
| `duplicate-attr`     | 同一块里重复写同一个键                      |
| `duplicate-tag`      | 同一实体重复写了同一个标签                  |
| `unused-time-anchor` | `time` 锚点声明了但没人用                   |
| `unused-entity`      | 实体没有被任何事件、关系或 `belong_to` 引用 |
| `unreferenced-event` | 声明了事件列表，但事件不在任何事件列表里    |
| `self-link`          | 关系边两端是同一个实体                      |
| `duplicate-link`     | 同一组里重复声明同一条边                    |
| `empty-block`        | 空的 `link` 或 `events`                     |

`weft rules` 会打印当前规则清单。

## 格式化约定

`weft fmt` 是可重复执行、幂等的格式化器，不改变语义，只统一外观：

- 2 空格缩进；顶层声明之间、属性组之间最多保留一个空行。
- 同一组属性的 `=` 按显示宽度对齐；空行或独立注释行会把对齐切成新组。行内注释不打断对齐。
- 列表能放进 88 列就写单行（`[a, b]`），否则每个元素一行并补尾逗号；列表内有注释时强制多行。
- `events` 在不超过 4 个事件且能放进 88 列时写单行，否则多行。
- 含换行的字符串写成 `"""..."""`；单行字符串统一转义。
- 名字只在必要时加引号；`link` 的关系一律加双引号。
- 注释（含行尾注释）原样保留；无法无损表达的布局不会被强行改写。
- 有语法错误时拒绝格式化，并打印诊断。

## 常见错误

| 诊断                                                                    | 原因 / 处理                                                         |
| ----------------------------------------------------------------------- | ------------------------------------------------------------------- |
| `syntax-error`                                                          | 少 `}` / `]`、属性缺 `=`、字符串没闭合。先看行号附近                |
| `missing-story`                                                         | 没有 `story` 块                                                     |
| `missing-field`                                                         | 缺必填字段，例如 `story.title`、`event.start`                       |
| `unknown-field`                                                         | `story` / `event` 写了表外字段；`entity` 不会报，会进 `extra_props` |
| `invalid-field`                                                         | 类型不对，例如 `description` 写成了裸标识符或列表                   |
| `unknown-time-ref`                                                      | 时间引用拼错，或引用了不存在的事件/实体/锚点                        |
| `time-cycle`                                                            | 两个事件互相 `start = 对方.start + ...`                             |
| `entity-cycle`                                                          | `belong_to` 成环；归属必须是有向无环图                              |
| `unknown-link-entity` / `unknown-event-entity` / `unknown-events-event` | 引用了未声明的名字，诊断通常会给 `did you mean` 建议                |
| `invalid-avatar-path`                                                   | 头像不存在或扩展名不支持                                            |
| `unknown-calculable-prop`                                               | 实体用了没在 `story.calculable_props` 注册的 ID                     |
